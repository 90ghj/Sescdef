КОМАНДЫ ДЛЯ МОДЕРАТОРОВ
=======================

Все команды пишутся ОТВЕТОМ на сообщение нарушителя.
Можно писать словом (мут) или через слеш (/mute) — работает одинаково.

МУТ — обязательно указать номер пункта правил (п.9):
  мут 1   — мат                         → 30 минут
  мут 2   — оскорбления                 → 1 день
  мут 3   — флуд                        → 1 час
  мут 4   — реклама, спам               → 1 неделя
  мут 5   — политика                    → 3 часа (сообщение удаляется)
  мут 6   — медиа/стикеры с матом       → 30 минут (сообщение удаляется)
  мут 7   — порнография                 → 1 неделя (сообщение удаляется)

  Без номера пункта бот откажет.

РАЗМУТ:
  размут  — снять мут (любой модер, по желанию)
  Мут, выданный ВЛАДЕЛЬЦЕМ, модеры снять или изменить не могут.

БАН:
  бан 7   — только при ПОВТОРНОМ нарушении п.7 (порнография)
  Другие баны — только владелец.

ПРОЧЕЕ:
  модеры   — список администрации
  правила  — показать правила

Что бот делает сам (вмешиваться не нужно):
  мат, оскорбления, флуд, политика, ссылки на 18+.
Рекламу (п.4) и медиа с матом (п.6) бот НЕ ловит — это делают модеры.

ВАЖНО: наказывать можно только по правилам. Все действия
записываются в лог. Наказание не по правилам = снятие с должности (п.9).

---------------------------------------
ТОЛЬКО ДЛЯ ВЛАДЕЛЬЦА:
  мут 2h / мут 30m / мут 3d / мут 1w — любой срок (m=мин, h=час, d=день, w=неделя)
  бан            — без причины
  разбан         — ответом или: разбан 123456789 (ID)
  /addmod        — назначить модером (ответом)
  /delmod        — снять модера (ответом)
